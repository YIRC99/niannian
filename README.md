# 念念提醒

原生 Android + Go 的个人邮件提醒工具。二次元卡通成长花园：创建任务是播种，真实完成是养分。AI 自然语言建任务，点击、文字或拍照完成，所有完成记录长期保留。服务器持续发送邮件，不依赖手机后台。

## 1.3.1 生长动画

完成小事后，会依次播放浇水、水滴、养分吸收与植物舒展；1 次发芽、3 次长叶、7 次开花，平时花园里的枝叶轻轻摇摆。可以重看动画，不会重复增加养分。离开页面或进入后台会停止，系统关闭动画时直接显示结果。

客户端和后端需一起更新到 1.3.1，动画才能使用本次完成前后的真实次数。旧后端仍可保存完成记录，客户端会提示更新，不推测植物阶段。

## 1.3.0 成长花园

- 全部主要页面统一暖白、柔绿的卡通风，内置生成的种子、幼芽、枝叶、花朵、浇水壶图标。
- 底部为“今天 / 花园 / 日历 / 我的”。一条提醒对应一株植物，1 次完成发芽、3 次长叶、7 次开花，之后继续累计养分。漏做不清零、不枯萎，已归档的完成记录继续留在花园。
- 花园展示真实全量累计、本周养分、植物列表和最近 12 次完成留念，可回看文字照片。邮件发送次数、打开次数及重复完成提交都不会变成养分。
- **客户端和后端一起更新到 1.3.0。** 旧后端仍可使用原有任务功能，花园会明确提示升级。更新后端需保留原 `data/` 和私人配置，不要同时启动两个后端进程。

## 开始使用

1. 将对应架构的 Linux 发布包上传并解压，运行 `chmod +x niannian && ./niannian`。默认监听 56507。
2. 安装 APK，在初始页面填服务器地址，例如 `http://192.168.1.10:56507`。手机上的 `localhost` 是手机自身；局域网调试要填电脑的局域网 IP。
3. 输入自己的邮箱，接收验证码并登录。任意有效邮箱均可使用，首次验证成功自动创建账号，再次登录进入原账号。登录会自动记住 90 天，退出登录会在服务端撤销令牌。
4. 点击新建，用一句话描述事情；生成后先看规则摘要，点“调整规则”可展开修改，也可以手动创建。
5. 在任务中点完成，可直接完成或附加文字、拍照/相册图片。“记录”按月显示日历，选择日期查看当天的未来安排、提醒与完成记录，点击查看详情。首页和详情中的开关可启用或暂停提醒。

当前给你的私人发布程序已内置提供的 DeepSeek 与 SMTP 配置，直接运行即可。密钥没有放入 APK 或 Git；本地 `backend/internal/config/defaults/secrets.local.json` 参与编译并被 Git 忽略。发布程序包含私人配置，仅用于自己的服务器。

## 支持哪些提醒

| 场景 | 时间 | 完成规则 |
|---|---|---|
| 公司月度申报 | 每月 1—15 日 09:00 | 本月完成一次就停，下月自动开始 |
| 洗衣服 | 指定一天 09:00、11:00，最多 2 次 | 做完就停，未完成也最多通知 2 次 |
| 每天拉伸 | 每天 20:00 | 每天分别完成，今天完成不影响明天 |
| 一周内办证 | 指定日期范围，每天 09:00 | 范围内完成一次就停 |
| 交材料，未完成一直提醒 | 从今天起每天 20:00，不设截止日 | 完成一次后永久停止 |
| 一次通知 | 指定日期时间 | 通知一次，无需完成 |
| 每周事务 | 选择周一、周五等 | 本周完成一次或每天分别完成 |
| 每隔几天浇花 | 起始日期 + 每隔 N 天 | 按日历日期计算，不随夏令时漂移 |

可设置每天多个时间、结束日期、提醒次数上限、暂停、恢复、稍后提醒和归档。支持 IANA 时区（默认上海），每月 31 日在短月按月末处理。

这是有明确规则的提醒工具，不宣称涵盖所有自然语言。农历、法定节假日、跨月日期窗口、每年重复等暂不支持；AI 会提示，手动规则也会校验，不会假装已按条件创建。

## 记录与邮件

- SQLite 与媒体默认放在运行目录的 `data/`。不需要安装数据库服务。
- 任务归档不会删除完成记录；编辑任务也保留原来的记录。
- 日历同时展示未来计划和实际记录，按手机时区归入日期。“每隔三天 12:00”创建后即可查看之后各个提醒日，切换月份继续查看。蓝色代表待提醒或仅通知类的已提醒，绿色代表已完成，黄色代表到点未完成，红色代表本期截止后仍未完成；邮件发送结果另行显示。
- 完成后停止本期的规则会移除本期后续计划，下一期仍保留。暂停或归档后不再显示未发送的计划，实际记录和照片保留。点进记录可查看对应任务，已归档任务仍可回看。
- 图片只允许登录的所有者读取；最大 10MB，支持 JPEG、PNG、WebP。
- 邮箱验证码 10 分钟有效，有发送频率与尝试次数限制；无需邮箱白名单，每个账号的数据独立。
- 成功发送的提醒会持久化去重；失败会有限次重试，可在应用中查看发送记录。
- 重启后只补发当天最近一个有效时间点，不集中补发过往所有邮件。新建任务不会补发创建前的时间点。
- SMTP 无法与本地数据库进行同一个事务。若服务器在“邮件已被 SMTP 接收，但发送记录尚未落盘”的瞬间断电，重试可能重复一封；普通重启与重复扫描已做去重。
- 拖过一个时间范围仍未完成的任务会标记到期，完成记录不会伪造。通知到达时间也受邮件服务商与收件箱过滤影响。

## 服务器配置

可在程序旁放 `config.local.json`，仅填写要覆盖的字段。参考 `backend/config.example.json`。配置优先级：内置默认 → 本地文件 → `NIANNIAN_*` 环境变量。

例如更改监听地址或数据目录：

```json
{
  "addr": ":56507",
  "data_dir": "data"
}
```

配置文件必须是合法 JSON，未知字段会报错。可用 `NIANNIAN_CONFIG` 指定文件路径。环境变量包含 `NIANNIAN_ADDR`、`NIANNIAN_DATA_DIR`、`NIANNIAN_DEEPSEEK_API_KEY`、`NIANNIAN_SMTP_USER`、`NIANNIAN_SMTP_PASSWORD` 等。旧配置中的 `allowed_emails` 和 `NIANNIAN_ALLOWED_EMAILS` 已停用，保留旧配置也不会限制登录。

公网使用建议通过 Caddy/Nginx 的 HTTPS 反向代理访问；应用也允许局域网 HTTP，方便本地与线上切换。切换地址会清除当前页面与登录态，旧连接的返回结果不会进入新页面，需要在新服务器重新登录。已经提交给旧服务器的操作仍可能完成。

长期运行和备份见 `deploy/README.md`。接口约定见 `docs/API.md`。

## 源码构建

后端：Go 1.26 或更高版本，`cd backend && go test ./... && go build ./cmd/server`。纯 Go SQLite，无 CGO；Linux 包包含时区数据。

安卓：Java 17/21、Android SDK 35、Gradle Wrapper。创建 `android/local.properties` 指定 `sdk.dir`，在 `android` 运行 `gradlew.bat --no-daemon assembleDebug`。发布 APK 使用独立签名密钥，升级要保留原签名文件。原文件为 `android/niannian-release.jks`，交付目录另有 `release/niannian-signing-backup.zip`，签名说明见 `android/README.md`；公开源码压缩包不含密钥与签名文件。

`scripts/build.ps1` 构建 Linux amd64/arm64 后端。源代码里没有私人密钥时仍能编译，通过配置文件填入 SMTP/AI 即可运行。

自动测试覆盖时间边界、完成周期、身份隔离、媒体归属、发送去重、持久化和 AI 输出校验。真实手机观感、相机权限及邮箱最终投递由实际使用验收。提醒由邮件触达，应用不请求系统闹钟或通知权限。

DeepSeek 接入依据官方 [JSON 输出](https://api-docs.deepseek.com/guides/json_mode/) 与 [思考模式参数](https://api-docs.deepseek.com/guides/thinking_mode/)；使用结构化 JSON 草稿，服务端二次验证。
