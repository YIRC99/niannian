# 念念本地管理端 · 2.6.0

直接双击 `index.html`，不需要安装依赖、启动服务或部署网页。支持账号增删改查、任务增删改查、提醒与管理日志、APK 上传发布/下架。

## 首次启用

1. 将后端更新到 2.6.0，保留原来的 `data/` 和私人配置。
2. 在后端原有 `config.local.json` 中增加 `"admin_key": "你生成的至少32位随机密钥"`，或设置环境变量 `NIANNIAN_ADMIN_KEY`。**保留原文件其他字段，不要整份覆盖。** 未配置或不足 32 位时管理功能关闭，普通用户功能仍可用。
3. 重启后端。双击本目录的 `index.html`，填写后端根地址（例如 `https://你的域名` 或 `http://IP:56507`）和相同的密钥。公网地址使用 HTTPS。
4. 首次将客户端手动安装到 2.6.0；更旧的客户端没有检查更新代码，无法靠服务器凭空获得此功能。

管理页仅记住服务器地址；密钥只在当前页面内存中，不写入本地存储。浏览器如询问本地网络访问，请允许访问所填后端。文件以 `file://` 直接打开，管理接口允许其 `Origin: null` 跨域预检，不使用 Cookie。

## 发布更新

1. 每次构建前提高 `android/app/build.gradle` 的 `versionCode`，更新 `versionName`，继续使用原来的正式版签名文件。
2. 进入“版本发布”，选择正式 APK、填写更新说明，点“上传并发布”。最大 200 MB；后端从 APK 清单读取包名和版本信息，拒绝同一 versionCode 重复上传。
3. 客户端启动自动检查，回前台每六小时最多自动复查一次；“我的 → 检查新版本”随时手动检查。不需要登录即可检查和下载。
4. 新版弹窗提供“稍后再说 / 下载更新”。下载后校验大小、SHA-256、包名、版本号、签名；随后打开系统安装器。首次需要用户允许念念安装应用，安装仍由系统要求用户确认。

最高且处于发布状态的 versionCode 是当前版本。下架后不再检查到该包，也不允许继续从服务器下载；不会给已安装高版本的用户降级。上传完成仅说明版本已发布，不说明所有手机已经安装。

安装包保存在 `data/releases/`，元数据和管理日志保存在现有 SQLite 数据库，备份时一起保留。反向代理需允许至少 201 MB 请求体和约 11 分钟上传超时（例如 Nginx 的 `client_max_body_size 201m`、`proxy_read_timeout 660s`）。

## 操作边界

- 账号可按邮箱或 ID 搜索；修改邮箱/密码使该账号现有登录失效。新建账号直接使用设定的密码登录。
- 删除账号需输入邮箱确认，会永久清除其任务、照片、记录及花园。已离线排程的手机提醒需设备联网同步或退出登录后撤销。
- 任务删除是归档，保留完成记录与花园；编辑、暂停、归档沿用正式任务逻辑，账号不变。新建任务可从账号行点“任务”，再点“新建任务”。
- 日志包含真实提醒执行结果及管理写操作的时间、接口、状态码；不记录管理密钥、登录密码或请求正文。管理操作最多保留约一万条，提醒记录沿用现有保留策略。

## 接口

全部管理请求使用 `Authorization: Bearer <admin_key>`，统一 `/admin` 前缀；普通客户端无需管理密钥，原有用户登录和账号隔离继续生效。

| 接口 | 用途 |
| --- | --- |
| `GET/POST /admin/users` | 查询 / 创建账号 |
| `GET/PUT/DELETE /admin/users/{id}` | 查看 / 修改 / 删除账号 |
| `GET/POST /admin/tasks` | 查询 / 创建任务（创建传查询参数 `user_id`） |
| `GET/PUT/DELETE /admin/tasks/{id}` | 查看 / 修改 / 归档任务 |
| `PUT /admin/tasks/{id}/paused` | 暂停 / 恢复任务 |
| `GET /admin/logs` | 提醒 / 管理日志，可传 `kind`、`user_id` |
| `GET/POST /admin/releases` | 版本列表 / multipart 上传（`file`、`notes`） |
| `PUT /admin/releases/{id}` | `{"published":true/false}` 发布状态 |
| `GET /api/v1/updates/latest?version_code=34` | 公开检查更新 |
| `GET /api/v1/updates/{id}/download` | 公开下载已发布 APK，支持 Range |

列表支持 `limit`（1–100，默认 30）、`offset`；账号/任务支持 `q` 搜索，任务支持 `user_id`。
