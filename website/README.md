# 念念介绍网页

静态官网，入口为 `index.html`。不需要安装依赖、编译或启动后端，直接双击即可预览。所有图片与字体都在本目录，没有远程字体、统计脚本和第三方运行依赖。

## 部署

将本目录中的 `index.html`、`styles.css`、`app.js` 和整个 `assets` 文件夹上传到网站根目录即可。也支持放在子目录下，资源均为相对路径。

- Nginx / 宝塔：将网站根目录指向上传后的目录，默认首页设为 `index.html`。
- 静态托管：发布目录填 `website`，构建命令留空。如果只上传这个文件夹，发布目录为当前目录。
- 不需要 SPA 路由回退、数据库、环境变量或接口代理。
- GitHub 仓库的 README 是项目介绍入口；此页面的“获取”链接指向仓库，不假设已有公开 APK 发布。

如果后续有公开安装包，可修改 `index.html` 的获取按钮，使用实际下载链接。不要把带私人配置的服务端程序或签名备份上传到这个网页目录。

## 内容与素材

参考 `UI设计/images/08-main.png` 和 `04-sowing.png`，沿用项目的庭院、种子与花卉插画。功能文案依据当前 `PRODUCT.md` 与 `README.md`：AI 可编辑安排、多渠道授权跟进、完成赚 3 滴水、浇水消耗 1 滴、成长 1/3/7 点以及 12 花种。

- 插画源自 `android/app/src/main/res/drawable-nodpi/`，仅为网页缩放压缩成 WebP。
- 实机图源自 `promo/xhs-20261004/assets/`，保留画面内容并压缩；页面明确标为早期版本，不冒充最新版实机验证。
- 手写字体使用已有 `garden_handwriting.ttf` 字符子集，只用于覆盖字符齐全的庭院木牌；许可见 `assets/FONT-LICENSE.txt`。
- 安排示例和花园浇水仅在浏览器中演示，不调用模型、不创建任务、不保存或上传数据。
