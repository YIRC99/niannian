## 复现

在项目目录执行（先有可用 Android 设备，手机安装需系统允许）：

```powershell
./scripts/test-android-logic.ps1
./scripts/ui-audit.ps1 -Group all -Serial <设备编号> -SystemScreens
./scripts/ui-audit-report.ps1 -RunDirectory work/ui-audit/<本次目录>
```

可按 `account`、`detail`、`editor`、`main`、`records` 分组；已构建或已安装时可用 `-SkipBuild` / `-SkipInstall`。脚本结束会停止两个独立测试包。临时模拟器已关闭，本轮没有启动项目后台服务；原有后端 PID 20372 保留。
