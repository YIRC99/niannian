# 念念思考动画

用户确认 2.5.1 布局后，要求 loading 不再只晃动整张静态图。本轮使用内置 imagegen，以原四表情种子为参考，生成 16 个连续动作帧；完整提示词在 `prompt.txt`，原始透明生成图为 `source.png`。

- 动作：倾听 → 眨眼抬手 → 托脸歪头、叶片跟随 → 再眨眼 → 放下手回到倾听。
- `thinking.gif`：256×256、16 帧、2.71 秒循环，暖白背景预览。
- `thinking-atlas.png`：4×4、每格 256×256 的透明帧图，Android 使用同一张图的资源副本；保留半透明边缘，不在 App 解码 GIF。
- `timing.json`：每帧时长。眨眼短、思考停留较长，循环首尾接回倾听。不是视频生成，也没有视频 API 依赖。
- `scripts/package-seed-animation.py`：只做切帧、等比统一缩放、脚底锚点对齐和 GIF 编码，原画来自 imagegen。运行命令：`uv run --with pillow python scripts/package-seed-animation.py`。

App 的 THINK 状态不再叠加整图摆动或旋转，真实动作来自帧内眼睛、手、身体和叶片变化；退出思考有 160ms 叠化，不等待循环完成、不伪造完成状态。后台、离屏、窗口失焦停止播放；系统关闭动画时展示静态托脸帧。正式请求、错误及保存逻辑保持不变。

已检查生成分格图及打包分格图，验证 GIF 帧数、时长及 PNG 透明通道。手机上的节奏和观感由用户体验，未将素材检查冒充实机视觉验收。
