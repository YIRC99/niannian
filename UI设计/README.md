## 文件与使用约定

- `images/`：24 张正式整板 PNG；`prompts/`：内置图片生成使用的提示词及修正记录。
- `参考/`：已确认的原稿及其提示词；[说明](说明.txt)和[检查记录](验收记录.txt)保留交付范围。
- 先看实际图片，再看当前代码；图片是视觉参考，业务语义以最新用户要求、当前功能和 [项目说明](../README.md) 为准。
- 客户端 1.9.0 已完成全部 72 状态的实现、模拟器及真机截图核对，截图证据、验证范围及复现方式见 [完成进度](完成进度.md)。不要仅因图片存在就标记开发完成。
- 示例账号、地址、任务、计数不能写进真实数据；系统相机、选择器和分享面板属于系统衔接示意。
- 已有可用素材在 [Android 图片目录](../android/app/src/main/res/drawable-nodpi/)，用途见 [素材说明](../docs/GARDEN-ART.md)。整张 UI 设计图不能当作可点击的 App 页面。
